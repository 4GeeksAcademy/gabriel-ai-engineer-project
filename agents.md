# Contexto requerido al iniciar cada sesión

Cada vez que inicies una sesión en este repositorio, lee estos archivos antes de continuar:

- `memory-bank/progress.md`
- `memory-bank/projectbrief.md`
- `memory-bank/techContext.md`

## Flujo obligatorio antes de cada commit

1. Revisa `git status` y el diff para identificar los cambios.
2. Ejecuta las pruebas o validaciones relevantes para esos cambios.
3. Revisa el diff final y corrige los problemas detectados.
4. Comprueba los archivos y el diff preparados para el commit; incluye solo los cambios previstos.
5. Crea el commit únicamente después de completar los pasos anteriores.

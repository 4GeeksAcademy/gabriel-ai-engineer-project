# Regla de desarrollo

**Alcance:** Siempre activa; aplica a todos los archivos y tareas de este repositorio.

Antes de modificar código, configuración o documentación, inspecciona el contexto directamente relacionado. Realiza el cambio mínimo que resuelva la solicitud y valida el comportamiento con la prueba o comprobación más específica disponible.

Para cualquier sistema o flujo que almacene, acceda o comparta datos de pacientes, identifica si aplica a EE.UU., Reino Unido o ambos y considera HIPAA y UK GDPR según corresponda. No afirmes que una solución cumple legalmente basándote solo en el briefing; señala la información faltante y deriva las decisiones de cumplimiento a Claire Whitfield.
